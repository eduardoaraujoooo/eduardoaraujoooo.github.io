Portfólio Pessoal
Este repositório contém o código-fonte de um portfólio pessoal desenvolvido em HTML, com o objetivo de apresentar informações profissionais, projetos, habilidades e formas de contato de maneira organizada e responsiva.

Sobre o Projeto: o portfólio foi criado para servir como uma vitrine digital, permitindo que recrutadores, clientes e visitantes conheçam melhor meu trabalho, experiência e projetos desenvolvidos.

🚀 Tecnologias Utilizadas
HTML5
CSS3
JavaScript (se aplicável)
